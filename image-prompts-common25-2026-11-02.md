# Ingredient photos: 25 common US ingredients (copy-paste blocks, ingredient-only)

Updated 2 Nov 2026. Each photo shows **just the ingredient**: no side foods unless one item shows how it's used (a single dipper in a dip, cocktail sauce with shrimp, mustard with soft pretzels). Each block already holds the subject, the house style, the size and the full do-not-show list, so you paste it as-is. If your tool has a separate negative-prompt field you can move the "Do not show" sentence there, but you don't have to.

**For each ingredient:** paste block A for the page photo (3:2), then block B for the Pinterest pin (2:3) in the same session so they match. Check the photo against the "Check before saving" line, then save as `charcuterielab/public/images/ingredients/<slug>.jpg` and `<slug>-pin.jpg`, at least 1200 px wide. When all are in, run `python3 scripts/make-thumbs.py` in `charcuterielab/` and add alt text to `src/data/ingredient-alt.json` from the finished photos.
